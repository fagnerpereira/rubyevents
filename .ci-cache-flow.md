└─────────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐

│ • PRESERVES existing data ✅                                 │
└─────────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│ Check Seed Cache                                             │
│ • Read tmp/seed_cache.yml                                    │
│ • Calculate checksums of all YAML files                      │
│ • Compare with cached checksums                              │
└─────────────────────────────────────────────────────────────┘
                           ↓
                    ┌──────┴──────┐
                    │             │
         ┌──────────▼──┐      ┌───▼──────────┐

## Key Differences

| Aspect | With Cache (`bin/ci`) | Without Cache (`--no-cache`) |
|--------|----------------------|------------------------------|
| Database command | `db:prepare` | `db:reset` |
| Existing data | ✅ Preserved | ❌ Dropped |
| Seed decision | Smart (checks changes) | Always re-seeds |
| Time (no changes) | ~5 seconds ⚡ | ~13 minutes |
| Time (with changes) | ~13 minutes | ~13 minutes |
| Use case | Daily development | Clean slate needed |

## The Magic: db:prepare vs db:reset

### `db:prepare` (with cache)
```ruby
# What it does:
if database_exists?
  if schema_needs_update?
    load_schema
  end
else
  create_database
  load_schema
end

# Result: Data is preserved! 🎉
```

### `db:reset` (without cache)
```ruby
# What it does:
drop_database    # 🗑️ Everything gone!
create_database
load_schema

# Result: Clean slate, must re-seed
```

## When to Use Each

### Use Cache (Default)
```bash
bin/ci
```
**When:**
- Normal development workflow
- Working on code (not data)
- Want fast feedback
- Running CI multiple times per day

### Force No Cache
```bash
bin/ci --no-cache
```
**When:**
- Database corruption suspected
- Schema changed significantly
- Testing seed process itself
- Before pushing (final verification)
- Cache seems stale
